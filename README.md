# Hadesr AI · Obsidian 插件

在 Obsidian 里写作时，选中文字就浮出胶囊「✦ AI ▾」；停手就在光标后猜下一句。
不用打开侧边栏，也不打断你打字。

## 功能

| 功能 | 说明 |
|---|---|
| **选中即胶囊** | 选中文字，浮出 `✦ AI ▾`。用过一次之后，按钮直接变成你上次用的动作（仅内存记忆，关闭文档即清空） |
| **16 个动作** | 润色 / 纠错 / 精简 / 扩写 / 简化语言 / 专业 / 口语 / 解释 / 总结 / 续写 / 转表格 / 转列表 / 转代码块 / 提取待办 / 翻译成中文 / 翻译成英文 |
| **AI 划范围** | 「让 AI 找出并标记…」→ 说「所有提到 U 盘的段落」→ 自动标记，**只标记不改正文**，你确认后再执行。大文档走两段式：先发章节目录让 AI 挑相关节，再只送这几节正文定位，token 少 5~10 倍、首字更快 |
| **标记多段** | 选中一段点「标记此段」，重复标记多段（关掉 Obsidian 即清空）；之后在 **AI 对话**里直接发指令即可作用到全部标记段，失败项可单独重试 |
| **快速改写** | 选中一段 → 说一句「改得更简洁」→ 直接出结果，可先「对比原文」再决定替换 |
| **行内补全** | 停手 0.4 秒后光标处出「AI 思考中」，接着逐字吐灰字。`Tab` 采纳、`Esc` 忽略、继续打字自动消失 |
| **AI 对话** | 可拖动浮动面板，支持引用笔记、提示词模板、多轮追问 |
| **引用回链** | 结果底部列出「参考了哪几篇」，点一下直接跳过去 |
| **差异预览** | 点「替换」之前逐行看清改了哪几行；可「复制改动行」只取变化部分 |
| **对话历史** | 自动记录「提问 + 回答」（不含正文），可在对话框「历史」里回看并继续 |
| **存为笔记** | 结果卡片一键把生成内容存成一篇新笔记（放当前笔记同目录） |
| **提示词可改** | 16 个内置动作的提示词都能改（带搜索框），随时恢复默认 |
| **转 Canvas** | 把当前笔记整理成 `.canvas`，自动分层排布 |
| **添加笔记属性** | 自动生成 title / summary / tags 写进 frontmatter |
| **三种接口格式** | OpenAI / Anthropic / Google，可自由添加多个，可为每个动作单独指定 |

## 安装

1. 下载本仓库的 `main.js`、`manifest.json`、`styles.css`
2. 放进你的库：`<你的笔记库>/.obsidian/plugins/hadesr-obai/`
3. Obsidian → 设置 → 第三方插件 → 关闭安全模式 → 启用 **Hadesr AI**

> 目录名必须是 `hadesr-obai`，与 `manifest.json` 里的 `id` 一致，否则加载不了。

## 第一次配置

设置 → Hadesr AI → **接口与模型**：

1. 填 API 地址（例如 `https://api.deepseek.com/v1`）、模型名、Key
2. 点「获取模型」拉列表，或选「✑ 手动输入…」
3. 点「测试连接」验证

支持本地服务（Ollama / vLLM / LM Studio 等），Key 可留空。

## 常用入口

| 想做什么 | 怎么做 |
|---|---|
| 改一段文字 | 选中 → 胶囊主按钮，或 `▾` 换动作 |
| 自由指令改写 | 选中 → `▾` → **快速改写…** |
| 打开 AI 对话 | 文档右上角 ✨（编辑/阅读按钮左边） |
| 开/关行内补全 | 命令面板「行内补全：开 / 关」 |
| 手动补一次 | 命令面板「行内补全：现在补一次」 |

所有命令都可在「设置 → 快捷键」里自行绑定。

## 隐私

- **API Key 只存在你本机的 `data.json`**，用 RC4 + base64 做了**混淆**（防随手一看，不是加密 —— 本地方案都这样）。
- 除调用你自己的接口外，不向任何第三方发送数据；无统计、无上报。
- 唯一的网络行为就是把你选中的文本/上下文发给你配置的那个 API。

## 移动端

核心逻辑与平台无关，已做触摸适配（点外面关闭、加大点击区域）。
行内补全依赖 Obsidian 内置的 CodeMirror 模块，移动端拿不到时会自动关闭补全，其余功能正常。

## 已知限制

- 行内补全依赖 Obsidian 内置的 CodeMirror 模块（未公开 API）。拿不到时会静默关闭补全，其余功能不受影响。
- 推理模型（会输出 thinking 的）在**非流式**下可能把 `max_tokens` 全用在思考上、正文为空 —— 补全会自动关思考（`reasoning_effort: none` 等三种写法依次尝试）。
